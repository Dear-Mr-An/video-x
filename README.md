# 神秘·X —— 视频处理工作台

视频帧混合与合成工具，基于 Qt6 浅色科技蓝工作台界面，使用 NVENC 硬件加速。
处理算法与输出结构经黑盒实验与结构对拍完整还原，输出与原程序在视频流、
时间轴表、SPS、容器结构上逐字节/逐字段对齐。

## 使用

```
python main.py
```

依赖：Python 3 + PySide6；需要 NVIDIA 显卡（NVENC 硬编码）。
`tools/` 目录放置 `ffmpeg.exe`、`ffprobe.exe`（不入库，请从 ffmpeg 官网下载放入）。

- 实拍视频：插入素材中的片段来源（循环使用）
- 素材视频：输出骨架，决定输出时长
- 支持任意分辨率 / 宽高比的素材（自动等比适应画布，竖屏横屏均可）
- 输出目录：输出文件名 = 素材名 + 模式后缀（重名自动加 `_2`、`_3`…）
- 批量处理：对素材文件所在目录下所有视频逐个处理
- 重复处理：同一素材生成 N 份

## 核心算法（逆向规格）

```
输出 60fps，总帧数 = 素材时长 × 60
画布 = 输出分辨率；源视频等比缩放适应画布后居中（黑边）

帧序列：
  前 intro 帧（默认 23）：素材帧 i//2（30→60fps 2x 上采样）
  之后每 cycle=(live+mat) 帧循环：
    前 live 帧 = 实拍，帧号 = floor(n*rate+0.25) mod N_head（rate=cycle/2/live）
    后 mat 帧  = 素材，帧号 = i//2（与输出时间 1:1，播完为止）

音频：素材音轨 → AAC 44100 stereo（无音轨则静音）
编码：h264_nvenc CBR，Main 3.2，GOP 18，B帧 3，bt709
```

## 输出伪装（与原程序一致）

| 项目 | 处理 |
|---|---|
| 时间轴 | stts 每帧 512（30fps 声明）；ctts v1 = pts[i]-512i+768；elst media_time=768；mdhd=last_pts+768 |
| SPS | HRD bit_rate 固定 10M、cbr_flag=0 |
| btrt | buffer=0 / max=10M / avg=0 |
| 编码器标记 | avc1 compressor name（默认 Lavc h264_nvenc） |
| 封装时间 | mvhd/tkhd/mdhd duration = 设定值（默认 11880 秒） |
| 魔法大小 | mdat size 字段 = 值 × 1_000_000（默认 670000000） |
| 清除 SEI | 移除全部 SEI NAL |

## 文件

- `main.py` — PySide6 图形界面（浅色科技蓝工作台）
- `ui_theme.py` — Qt6 样式、矢量图标与品牌组件
- `2.png` / `2.ico` — 软件图标与界面 Logo
- `engine.py` — 处理引擎（帧调度 / 编码 / MP4 后处理补丁）
- `tests/test_ui.py` — UI 回归测试（unittest，可离屏运行）
- `tools/` — ffmpeg / ffprobe（不入库，自行下载放入）

## 对拍结论

同输入下与原程序输出对比：

- stts / ctts / elst / mdhd / mvhd / tkhd：完全一致
- SPS / btrt / avc1 标记：完全一致
- 帧内容：逐帧一致（差异 < 0.3/255，为 NVENC 版本间编码噪声）
- 文件大小：偏差 < 0.05%
- 音频：编码器实现差异，时长偏差约 8ms
